# Jualan Kitab Darul Hikmah

App ringkas untuk merekod jualan kitab dan menjejak stok.

- **Frontend:** `index.html` (satu fail HTML + CSS + JS, tiada build step), dihidang melalui GitHub Pages.
- **Data:** Google Sheet, melalui Google Apps Script (`doPost`, `fetch` `text/plain`).
- **Edit** memerlukan PIN. PIN hanya disimpan di backend dan tidak ada dalam repo ini.

Untuk kemas kini, commit `index.html` ke `main`. GitHub Pages akan mengemas kini laman dalam 1–2 minit.
